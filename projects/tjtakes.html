TJTAKES: Timed Writing Practice Test

PrototypeHTMLCSSJavaScript

A practice site that mimics the written part of the TJHSST admissions test, with timed writing, character limits and prompts loaded from a Google Sheet.

How it works

  • Pick a test type (PSE + narratives, PSE only, or narratives only) and paste a link to a Google Sheet that holds the prompts
  • The timer starts when you first click into an answer, and each answer box shows a live character count
  • Submitting opens a pre-filled Gmail draft with all of your responses, so nothing is stored on a server

RServer: Self-Built Home Server

RunningLinuxDockerTailscaleSecurity

A private server running on an old laptop. I wiped Windows, installed Ubuntu Server, and have been building it up in phases, one working result at a time. It started on 2026-11-06, and I keep a full log of every decision in my notes.

What's running

  • Ubuntu Server 26.04 LTS on a Dell laptop, wired over Ethernet with Wi-Fi as a fallback, and it powers itself back on after a real power cut
  • Docker for apps, with Uptime Kuma monitoring and AdGuard Home for DNS filtering
  • Tailscale for private access from my PC and phone, with a policy that only lets devices reach the server
  • Alerts by Telegram, plus an outside heartbeat check that fires if the monitor itself goes quiet
  • Nightly encrypted backups with restic to an external drive, and I tested a full restore

Security work

  • SSH with keys only, and password logins off
  • A firewall that only allows what's needed, with SSH limited to home and my private network
  • A first security audit with external port scans and a Linux hardening scan, then fixes from the results

Things that broke, and what I learned

  • Wi-Fi wouldn't connect for hours. The root cause was one missing package, found and fixed from a USB stick.
  • DNS lookups started failing after I changed DNS settings for AdGuard, because Tailscale quietly took over the resolver. The fix was to turn off its DNS takeover. I wrote up the whole timeline.
  • Exposing a server to the internet should wait until a list of gates is closed, so I wrote the gates down first.

What's next

RServer Cloud: a family file and photo cloud that I decided to build myself instead of using an existing product. It is private to my own network, never public, and it's in the design stage. I haven't started building it yet, so I'm not listing it as a feature.

Not done yet

  • A BIOS update is on hold until I replace the laptop battery
  • A second backup drive and an off-site backup copy
  • Blocking the server from reaching the rest of my home network

My C# work, from the Unity learning pathway to a game of my own built on top of one of the prototypes (June to July 2025).

What's here

  • Unity Essentials pathway and Create with Code Prototypes 1 to 4 (driving, feeding animals, a side-scrolling runner, a sumo-style arena)
  • Jump. Spend. Evolve.: my own game built on the runner prototype, with a title screen, score, pause and resume, and an end screen with restart
  • Room Rumble: a 2D sword platformer where the art and animations are finished, but I haven't written the gameplay scripts

What I learned

  • Gravity in Unity is global and survives scene reloads, so multiplying it on every restart compounds. Setting an absolute value fixes it.
  • When pausing with time scale zero, reset it to one before reloading a scene, or the restarted game stays frozen.

Status

The game-over and pause flow work. The spending and evolving mechanics the name promises were never built. Repos are private.

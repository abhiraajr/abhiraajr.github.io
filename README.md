# abhiraajr.github.io

My portfolio site: https://abhiraajr.github.io

A single static page (`index.html`, no build step, no framework). Edit `index.html`, commit, and GitHub Pages publishes it.

- `images/` holds the logo and favicon.
- `sitemap.xml` lists the one page.
- `.nojekyll` tells GitHub Pages to serve the files as they are.

The old Jekyll template this repo started from was removed on 2026-11-16.
